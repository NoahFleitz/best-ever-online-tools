How to use Extract Audio (free, no upload)

  1. Choose or drop a video (or an audio file you want to convert).
  2. Pick a format: MP3 plays everywhere, M4A is smaller at the same quality, WAV is uncompressed for editing.
  3. Optionally set a start and end to keep only part of it.
  4. Click Extract audio and download the file.

Frequently asked questions

Which format should I pick?

MP3 at 192 kbps is the safe choice for music and podcasts. Pick WAV if you're going to edit the audio further.

Can I convert an audio file too?

Yes. Drop an MP3, WAV, M4A or other audio file and save it in a different format.

The tool says there's no audio. Why?

The video has no sound track, or it uses an audio format your browser can't read.

Is my file uploaded?

No. Everything runs in your browser.
